# 🚀 DevCraft Career: Next-Generation Full-Stack Career Optimization Engine

DevCraft Career is a commercial-grade, full-stack career development lifecycle platform. It features a high-performance dual-track framework: an automated project card synchronizer for **Software Engineers** and a high-density, single-column typographic document engine optimized to achieve maximum compatibility scores against corporate **Applicant Tracking Systems (ATS)** filters.

Live Production URL: [https://vercel.app](https://vercel.app)

---

## 🛠️ Complete Systems Architecture Matrix

The platform is compiled utilizing low-overhead engineering tools to achieve near-instantaneous edge caching performance:

-   **Core UI Layout Matrix:** Next.js (App Router with client-side state caching structures)
-   **Utility Design Engine:** Tailwind CSS (Fluid utility layers with explicit dark mode themes)
-   **Interface Icons Kit:** Lucide React (Clean, version-stable graphic vector tokens)
-   **Database Layer Infrastructure:** Supabase Cloud (Relational PostgreSQL structures)
-   **Authorization Security Guard:** Supabase JWT Auth (Bypassed email links, supporting GitHub OAuth handshakes)
-   **Object File Vault:** Supabase Storage (`resume-docs` public bucket directory distribution paths)
-   **Continuous Deployment Pipeline:** Vercel Global Edge Network (Silent automated builds on push)

## 💎 High-Utility Platform Features Ecosystem

### 💻 1. Programmer Portfolio Dashboard Terminal
-   **Vanity Link Subdomains:** Claim clean handle identifiers pointing directly to unique profile viewers paths (`/p/username`).
-   **GitHub Project Card Miner:** Input a repository URL, click sync, and the backend miner dynamically extracts information to auto-populate cards.
-   **Profile README Exporter:** One-click copy tool compiles typed engineering bio stacks into formatted Markdown scripts ready for GitHub profiles.
-   **Automated Lead Sourcing Radar:** Scans typed technical stack keywords to calculate matching scores and display active contract openings on screen.

### 📄 2. ATS-Optimized CV Engine Suite
-   **Zero Parsing Rejection Filters:** Generates semantic HTML typography that automatic screeners can index smoothly without automatic bot rejections.
-   **Dynamic Theme Stylesheet Switches:** Flip document presentation orientations between Corporate Minimalist, Modern Indigo Accent, or Executive Slate layout sheets.
-   **Local Phrasing AI advisor:** Computes work history descriptions in real-time to alert against passive text and recommend metrics-driven adjustments.

### 📋 3. Kanban Application Search Tracker CRM
-   **Search Pipeline Board Lanes:** Move opportunity cards through *Applied, Interviewing, Offered, or Rejected* stages instantly.
-   **Optimistic UI Syncing:** Moves cards visually on click while silently writing changes to the PostgreSQL backend to guarantee zero user network lag.

### 🔍 4. Administrative Control Console
-   **Administrative Statistics Panels:** Restricted root terminal route (`/admin`) evaluating total platform user volumes and account track registration splits.
-   **Live Telemetry Log Shell:** Auto-scrolling terminal window (`/admin/logs`) monitoring live database handshake speed and server network latency.
